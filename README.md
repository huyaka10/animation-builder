# Lottie to SVG Converter

Один файл приложения: `index.html`.

Локальная страница-конвертер с шагами:
1. **Импортировать JSON**
2. **Экспортировать в SVG**

## Запуск

Из папки проекта запустите:

```bash
python3 -m http.server 8000
```

Откройте в браузере:
- `http://localhost:8000/`
- или `http://localhost:8000/index.html`

## Если видите "Not Found"

Обычно это значит, что сервер запущен не из папки проекта.
Убедитесь, что перед запуском вы находитесь в директории, где лежит `index.html`.
