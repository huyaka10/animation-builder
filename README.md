# Lottie to SVG Converter

Локальная страница-конвертер с явными шагами:
1. **Импортировать JSON**
2. **Экспортировать в SVG**

## Запуск

Из папки проекта запустите:

```bash
python3 -m http.server 8000
```

Откройте в браузере:
- `http://localhost:8000/` (теперь ведёт на конвертер автоматически)
- или `http://localhost:8000/lottie-to-svg.html`

## Если видите "Not Found"

Обычно это значит, что сервер запущен не из папки проекта.
Убедитесь, что перед запуском вы находитесь в директории, где лежат `index.html` и `lottie-to-svg.html`.
