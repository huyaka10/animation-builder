# Lottie to SVG Converter

Один файл приложения: `index.html`.

Конвертер делает **полностью автономный анимированный SVG**:
- импортирует Lottie JSON,
- рендерит покадрово,
- сохраняет один `.svg` без внешних JS/CDN зависимостей.
- перед экспортом можно выбрать направление: **Forward** (как в Lottie) или **Reverse**.
- можно включить/выключить флип по вертикали (он применяется и к превью, и к итоговому SVG).
- можно выбрать режим анимации: **CSS покадрово**, **встроенный JS** или **Trim/Dash (экспериментально)** в самом SVG.
- в режимах CSS/JS кадры остаются векторными (встроенные SVG-элементы, не PNG/JPG).

## Запуск

Из папки проекта запустите:

```bash
python3 -m http.server 8000
```

Откройте в браузере:
- `http://localhost:8000/`
- или `http://localhost:8000/index.html`

## Важно

- Размер экспортируемого SVG фиксирован: **320×320px**.
Автономный SVG экспортируется как последовательность встроенных ВЕКТОРНЫХ SVG-кадров с CSS-анимацией
(без PNG/JPG внутри), поэтому итоговый файл может быть значительно больше исходного JSON.


- Trim/Dash режим анимирует stroke через `stroke-dasharray`/`stroke-dashoffset` для найденных stroke-сегментов.

- В режиме Trim, если stroke-сегменты не найдены, экспорт завершится ошибкой (без скрытого fallback на CSS).
