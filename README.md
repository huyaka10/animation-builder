# Lottie to SVG Converter

Локальная страница-конвертер с явными шагами:
1. **Импортировать JSON**
2. **Экспортировать в SVG**

## Запуск

Откройте `lottie-to-svg.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000/lottie-to-svg.html`.
