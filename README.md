# Lottie to SVG Converter

Один файл приложения: `index.html`.

Конвертер делает **полностью автономный анимированный SVG**:
- импортирует Lottie JSON,
- рендерит покадрово,
- сохраняет один `.svg` без внешних JS/CDN зависимостей.

## Запуск

Из папки проекта запустите:

```bash
python3 -m http.server 8000
```

Откройте в браузере:
- `http://localhost:8000/`
- или `http://localhost:8000/index.html`

## Важно

Автономный SVG экспортируется как последовательность встроенных SVG-кадров с CSS-анимацией,
поэтому итоговый файл может быть значительно больше исходного JSON.
