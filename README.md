# CRT Rod Field

A self-contained canvas animation inspired by the provided pixelated blue/yellow CRT reference image. The visual is intentionally abstract: a noisy blue field and bright yellow/white rod clusters flicker, bleed, and slowly exchange color intensity.

## Run locally

Open `index.html` in a browser, or serve the directory with any static file server:

```bash
python3 -m http.server 8080
```

Then visit <http://localhost:8080>.
